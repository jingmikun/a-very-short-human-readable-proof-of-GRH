# a very short human readable proof of GRH

An 11-page mathematical exposition of the proof of the generalized Riemann hypothesis for Dirichlet L-functions. It uses the arithmetic estimates in Przemek Chojecki's [*Covolumes and Dirichlet Zeros*](https://www.ulam.ai/research/grh_complete.pdf), based on [Levent Alpöge's theta-lift argument](https://alpo.ge/remark.pdf), and gives the determinant comparison and the passage from the prime-sum bound to the critical line.

- [Read the manuscript](dirichlet-grh.pdf)
- [LaTeX source](dirichlet-grh.tex)

To compile the manuscript, run `tectonic dirichlet-grh.tex`.
